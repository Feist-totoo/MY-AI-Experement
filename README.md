# MY-AI-Experiment 项目文档

## 项目概述
**MY-AI-Experiment** 是一个面向人工智能基础理论、认知科学与量子物理领域的个人研究与实验项目。本项目通过轻量化前端实现，对前沿交叉学科中的经典概念进行可视化解析与逻辑呈现，旨在构建一套可直接运行、便于理解的概念演示工具集，服务于个人学习、知识沉淀与技术探索。

项目当前包含两个核心演示模块，分别聚焦**认知科学（反转光谱悖论）**与**量子物理（电子云模型）**，通过结构化文档与可视化界面，降低抽象理论的理解门槛，为后续AI相关研究提供理论基础支撑。

---

## 核心模块详细说明

### 1. Inverted Spectrum Paradox.html
**模块名称**：反转光谱悖论解析演示
**所属领域**：认知科学、心灵哲学、人工智能意识理论

#### 核心功能
- 系统性解析**反转光谱悖论**这一经典思想实验，完整阐述其理论背景、逻辑结构与哲学意义；
- 以清晰、结构化的文本与可视化形式，展示“主观感知差异无法被客观检测”的核心命题；
- 探讨**感受质（Qualia）**、物理主义、意识本质等与人工智能通用智能研究高度相关的基础问题；
- 提供可直接在浏览器中打开的独立演示页面，无需依赖任何后端服务或第三方库。

#### 适用场景
- 认知科学与AI意识理论学习
- 哲学思想实验可视化演示
- 个人知识梳理与研究笔记展示

---

### 2. 电子云.html
**模块名称**：电子云模型可视化演示
**所属领域**：量子物理、原子结构、科学可视化

#### 核心功能
- 准确呈现量子物理中**电子云**的标准定义，区别于经典轨道模型，强调概率密度分布的核心思想；
- 以可视化形式展示原子核外电子的空间分布规律，解释s轨道、p轨道等基础轨道形态；
- 使用前端技术实现原子结构的直观呈现，降低量子物理概念的理解难度；
- 独立HTML页面，支持本地直接运行，适合教学演示与自学使用。

#### 适用场景
- 量子物理基础概念学习
- 原子结构可视化演示
- 科学可视化实验与实践

## 环境与运行说明
### 运行要求
- 任意现代浏览器（Chrome、Edge、Firefox、Safari 均可）
- 无操作系统限制（Windows / macOS / Linux 通用）
- 无第三方依赖、无需安装环境、无需联网

### 快速启动
1. 克隆或下载项目文件到本地
2. 直接双击打开任意 `.html` 文件
3. 浏览器自动加载并展示对应模块内容

### 开发配置（可选）
- `.vscode/tasks.json` 为VS Code开发环境任务配置文件
- 用于快速启动本地服务、自动刷新预览、代码格式化等开发辅助
- 不影响模块的正常运行与使用

## 项目特点
1. **轻量化与独立性**
   所有模块均为纯前端实现，无需服务器、无需数据库，开箱即用。

2. **理论性与教育性**
   聚焦认知科学、量子物理与AI交叉领域，适合学习、演示与知识沉淀。

3. **可扩展性**
   项目结构清晰，可继续新增更多概念演示模块（如量子纠缠、图灵测试、中文屋论证等）。

4. **实验性**
   作为个人AI方向的探索项目，强调理论理解、可视化表达与技术实践结合。
